# Leone University Think Tank

Standalone Vite + React build of the Leone University site (originally built on Base44), deployed to GitHub Pages:
https://charlesanthonyleone.github.io/leone-university/

- `npm install --legacy-peer-deps && npm run dev`
- Pushes to `main` deploy via GitHub Actions.
- Idea records live in `src/data/ideas.js` (the Base44 backend was offline, so none could be exported).
